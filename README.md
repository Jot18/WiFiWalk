# WiFiWalk

Offline native Android Wi-Fi signal survey app. Import a floor plan, sample connected Wi-Fi RSSI on tapped locations, inspect access-point identifiers and export CSV. No AI, accounts, or cloud uploads.

## Build

GitHub Actions builds a debug APK on pushes. Open the [Actions tab](https://github.com/Jot18/WiFiWalk/actions) and download the `WiFiWalk-debug` artifact after a successful run.

Source: Kotlin + Android SDK 35. Release 0.1 is an MVP and not yet device-tested.
